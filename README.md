# 🌍 TripAdvisor Clone

A responsive front-end clone of **TripAdvisor**, built using vanilla **HTML5** and **CSS3**. This project replicates the core user interface and layout of the popular travel and restaurant review platform, focusing on clean design and modern styling.

---

## 🚀 Features

*   **Responsive Homepage:** Styled navigation bar, hero section with a search bar, and category filters (Hotels, Things to Do, Restaurants, etc.).
*   **Explore Sections:** Grid layouts showcasing popular destinations, top-rated hotels, and traveler experiences.
*   **Card Components:** Reusable card designs for places and reviews featuring rating stars and image overlays.
*   **Modern CSS:** Built entirely with pure CSS (utilizing Flexbox and CSS Grid) without relying on heavy external frameworks or JavaScript.

---

## 🛠️ Built With

*   **HTML5** – For semantic structure and content layout.
*   **CSS3** – For styling, layout design (Flexbox/Grid), and responsiveness.
*   **FontAwesome** – For icons (search, stars, navigation symbols).
